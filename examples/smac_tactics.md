# SMAC Tactical Doctrine Example

This document is a placeholder for long-term tactical knowledge that can be
loaded into TrustGraph Library and processed with an ontology flow.

If an enemy unit has low health and is within allied weapon range, the preferred
tactic is focus_fire.

If multiple allied units have low health and enemies are close, the preferred
tactic is retreat or kite.

If allied units are split across the map and no enemy unit is near death, the
preferred tactic is regroup.

If allied units control a choke point and enemy units must pass through it, the
preferred tactic is hold_position.
